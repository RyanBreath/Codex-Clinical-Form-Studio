## API 示例與實錄要求

- 請求區以遮蔽值 `Bearer <redacted>` 呈現正式認證概念；實際 Development 請求須清楚標示所用模式，不能剪接成已連接正式 IdP。
- 每個請求同步保存遮蔽後的 request／HTTP status／response 證據，影片不只顯示預先寫好的成功文字。
- API payload 與錯誤碼以實際回應為準。來源程式只放關鍵幾行，不露出無關工作區、其他專案或憑證。
- 草稿建立與正式送出分開；外部建立不宣稱完成 submit、review 或 lock。控制動作由平台授權角色完成。
- 範例 code、schema 與影片原稿共存於專案，生成的影片／字幕／錄影證據維持忽略版控。
