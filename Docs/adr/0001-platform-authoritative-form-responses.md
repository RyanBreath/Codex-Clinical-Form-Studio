# 本平台保存研究表單的正式填答紀錄

為支援 CTMS 與其他系統使用研究表單，選擇由本平台保存正式填答、表單版本關聯與更正歷程，整合系統透過 API／事件取得資料及狀態。相較於讓每個整合系統各自保存正式填答，這個選擇可集中提供驗證與追溯能力，但本平台須承擔資料保存、存取控制、備份還原與維運責任；使用者於 2026-10-21 選擇此方案（A）。

外部副本不形成另一份可獨立更正的正式填答；更正須經本平台受控流程。操作入口與交付順序見 ADR 0002；受控外部寫入 API 見 ADR 0016，同步契約仍待設計。本決策不表示本平台接管 CTMS 全部資料，也不決定法律上的資料權責。
