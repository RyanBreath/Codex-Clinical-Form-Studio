# 以訪視與可重複表單管理資料收集

使用者選擇第一版由研究定義訪視及所需表單，支援非預定訪視，並依設定允許同一表單多次填寫，而非僅以獨立填答及自由文字日期用途管理。填答須明確關聯受試者、訪視、表單版本及填寫次數，以支援應收、已收與缺漏狀態供 CTMS 使用。

本平台負責研究資料收集關聯，完整訪視排程與行政管理留給 CTMS。訪視定義與實際訪視須分開，非預定訪視仍需穩定識別；表單重複次數不是填答修訂版本。CTMS 脈絡維護模式下的訪視識別來源、可重複規則、未執行與不適用原因、訪視變更及缺漏判定仍待詳細設計。
