# 依研究指定 CDISC 對應的發布要求

使用者選擇由研究指定哪些 eCRF 欄位須完成 CDISC 對應；必要欄位未完成時阻擋正式發布，其餘未對應欄位顯示提醒。相較於所有欄位一律強制或完全不影響發布，此政策兼顧研究特有資料收集與標準化要求；AI 僅提供候選與來源，對應須由人員確認，ICF 說明段落不套用 eCRF 逐欄編碼要求。

須保存研究編碼政策、適用範圍與版本，未要求對應不得被表示為已符合 CDISC，也不免除欄位型別、驗證規則及其他發布檢查。必要欄位可否以不適用及理由結案、政策修改後的影響檢查與權限仍待設計。既有 Studio／compiler 有未解決 mapping 阻擋產出的規則，後續須明確銜接研究政策，不能僅移除檢查或把未對應值偽裝為已確認。
