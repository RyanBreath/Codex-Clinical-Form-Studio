# 已簽 ICF 依研究設定保管方式，預設留在院端

使用者選擇依研究設定已簽 ICF 集中或院端保存，預設採院端保管；需要集中查核的研究才開啟受限文件上傳與存取。本平台保存 ICF 版本、簽署日期、確認人、同意狀態及院端文件編號等查核資訊，讓一般研究工作以研究代碼及狀態進行，降低不必要的姓名與簽名集中保存。

此安排不改變 ADR 0001 的正式填答保管責任；文件保管位置與同意狀態正式紀錄位置是不同概念。集中保存須獨立設定已簽 ICF 的存取權，不能沿用一般 eCRF 或資料分析權限。可否依院所例外設定、院端文件可取得性的查核、保管方式變更、保存期限及撤回處理仍待設計；文件收件不自動代表有效同意。
