# 第一版提供 eCRF 收集及 ICF 文件管理

使用者選擇第一版涵蓋 eCRF 建立、CDISC 對應、發布、填寫、審閱、更正及匯出，並提供 ICF 文件建立、核准版本、已簽文件與同意狀態管理；交付順序先跑通 eCRF 收集，再加入 ICF 管理。這讓第一版可連結同意依據與研究資料，同時將完整線上知情同意、電子簽署、提供簽署副本及重新同意流程的設計與驗證留待後續階段。

ICF 文件收件與狀態登錄不能自行證明有效知情同意。已簽文件是否集中存放全文、同意狀態由誰確認、如何處理核准免同意及各類資料用途限制，仍需後續決策；本決策不表示任意電子簽名或文件上傳可取代院所核准流程。
