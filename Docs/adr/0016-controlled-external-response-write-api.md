# 提供受控外部填答寫入 API

使用者選擇除嵌入表單、讀取紀錄與狀態整合之外，另提供外部系統經授權新增或更正填答的 API，以減少重複輸入。交付順序先完成表單填寫與資料讀取，再開放受控寫入；外部寫入須遵循與平台介面相同的欄位驗證、表單版本、研究／院所權限、重新審閱及鎖定規則，不形成可繞過控制的匯入通道。

匯入須保留來源系統、外部紀錄 ID、實際執行身分及可取得的原始填寫者資訊，並區分系統帶入與人員確認。外部聲稱的原始填寫者資訊屬來源資訊，不能取代本平台對呼叫者的身分與授權判定。API 呼叫授權、重複請求、同時修改衝突、部分失敗、來源紀錄更正對應及回傳契約仍待設計；正式填答仍以本平台為準。
