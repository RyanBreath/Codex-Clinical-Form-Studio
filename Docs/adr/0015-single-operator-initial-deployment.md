# 第一版由單一營運單位管理多研究與合作院所

使用者選擇由單一營運單位管理一套平台，承接多個研究及合作院所；第一版不採多個獨立客戶自行管理的共用 SaaS，也不以每客戶獨立部署作為交付要求。這將第一版集中於既有研究與院所合作流程，減少租戶管理、客戶自助治理及多套部署維運的範圍。

須保留清楚的組織與研究識別及模組責任，供日後評估擴充；這不代表第一版已提供可商用的多租戶隔離。單一營運單位不改變 ADR 0013 的院所隔離與明確跨院授權，也不表示營運人員可讀取所有研究內容。實際雲端或院內部署位置、環境隔離、備份與復原目標仍待設計。
