# 研究工作台 UI／UX 設計

更新：2026-10-28。依使用者指定採實用、高資訊密度的工具型介面，應用於本機 MVP 工作區、表單預覽與嵌入填寫入口。

## 視覺規格

- 中性灰白畫布與冷藍 `#315fce` 強調色；無紫色、霓虹、毛玻璃或漸層。
- 卡片 6px 圓角、1px 灰色邊框、無投影。以邊框、文字及狀態標籤建立層級。
- 標題使用緊字距；欄位標籤、代碼、數據、版本、日期與狀態採本機 monospace 字型，不請求外部字型。
- 桌面側欄約 216px；工具列、輸入及按鈕採緊湊間距。表單設計使用欄位清單／設定／預覽的不等寬工作區。
- 窄螢幕導覽改為橫向捲動，內容依序堆疊；資料表在區塊內捲動，右側開啟操作固定可見。

## 總覽資訊與操作

上方資料列顯示可見受試者、院所、待填表單、待審閱及鎖定數量。資料由既有授權 API 取得；待填數只依已建立訪視計算，不預估未建立訪視。

主區採訪視工作清單，支援代碼／訪視／表單文字搜尋、全部／待填寫／待審閱／已鎖定篩選。每列可開啟對應受試者及訪視的資料收集頁，保留既有授權與狀態控制。

右側集中研究政策及流程入口；不顯示假活動、假趨勢或未計算的百分比。載入、請求失敗及沒有符合條件的資料分別顯示。

## 實作邊界與驗證

`platform.css` 管理工作台 tokens；`FormRenderer.module.css` 的 compact 類別只用於 platform／preview，原有獨立 demo 樣式保留。未新增 UI 函式庫或改動資料庫、收集規則及研究授權。

前端 53 個測試及 3 個 Node 原生測試通過，另 1 個條件式略過；TypeScript 檢查及本機發行包建置成功。瀏覽器在 1440px 與 390px 寬度驗證搜尋、篩選、正確訪視導向及頁面無水平溢出。總覽與收集頁的 axe WCAG 2 A／AA 自動檢查均無違規；此結果不等於完整人工無障礙認證。

驗證腳本：`scripts/platform-ui-smoke.js`，搭配已完成 MVP 驗收的合成研究。畫面證據位於 `output/playwright/ui-20261028/`。
