# 研究表單平台開發狀態

更新日期：2026-10-28。完整目標仍依規劃書與 ADR 0001–0019；本檔記錄實際進度，不縮小已授權範圍。已交付可在本機以合成資料試跑的 MVP，完整規劃的後續工作仍保留；詳見 [MVP 驗收紀錄](mvp-acceptance.md)。

## 已有可執行實作

- .NET 10 API、PostgreSQL migrations、隔離的本機 Compose 資料庫。
- 研究、院所、人員指派／撤銷、研究代碼、預定／非預定訪視。
- 表單草稿、版本、送審、禁止設計人自審、固定內容發布、版本採用與重複次別。
- ICF 草稿／編輯／獨立核准／固定雜湊／停用，收集依據登錄／確認／撤回及後端關卡。
- 填答保存、送出、更正、重新審閱、鎖定／解鎖、修訂、稽核與待送事件。
- 資料疑問建立／回覆／結案 API 與操作介面。
- 授權範圍收集進度、未執行理由／恢復、固定修訂 JSON 匯出及最近稽核檢視。
- CTMS 來源綁定、外部受試者／訪視代碼、寫入／更正、去重收據與來源追溯。
- 固定表單獨立入口、同源嵌入示範、CSP 父頁來源控制與狀態通訊。
- 受授權範本庫跨研究採用、平台帳號管理介面、本機發行包及資料庫還原演練。
- OIDC Code + PKCE、Cookie／CSRF、受控帳號登錄及停用 API；正式高權限操作檢查近期 MFA。
- 研究工作入口、視覺化欄位編輯與預覽、YAML／JSON 草稿匯入、基本指派及填答操作。
- 新增契約 1.2，允許研究政策管理未完成對應；保持舊契約限制。

## 已取得驗證

- 最新後端 22 個測試通過：涵蓋合約引擎、多院隔離、依據關卡、獨立核准、填答生命週期、Query、固定匯出、受控整合寫入、未執行／恢復與版本識別一致性。
- 前端 53 個測試通過、1 個因未提供外部規格檔路徑而略過；另有 3 個 Node 原生測試通過。TypeScript 檢查及平台建置成功。
- Playwright 已完成合成資料的獨立發布、採用、依據確認、填答、重新載入持久化、審閱、鎖定及匯出。
- 本次追加瀏覽器驗證：未執行理由、保持選取訪視、重新載入與恢復收集；另建 2.0.0 草稿並比較契約差異。新瀏覽器流程沒有 console error。
- 隔離的本機 Keycloak 已驗證登入、Cookie + CSRF 建立合成研究、缺 CSRF 拒絕及登出；不代表正式 IdP／MFA／撤銷已驗收。
- 證據位於 `output/playwright/platform-20261028/` 與 `output/platform-tests/platform-current.trx`。

## 已知驗證限制

- 曾有一輪完整測試的整合寫入案例失敗；單案與後續兩輪完整測試均通過，目前未取得可重現條件，尚不能判定原因已排除。
- 已分割工作區與嵌入入口，最大 JavaScript chunk 約 212 kB，建置不再有先前的 500 kB 提醒；正式容量驗收仍未完成。

## 必須繼續完成

- 強化契約前後端一致性與對應政策測試、來源阻擋事項與正式核准的銜接。
- 完整跨研究範本庫、受控升版採用與更完整差異語意呈現；目前已有完整契約路徑差異、升版識別檢查、訪視／重複次數採用設定。
- 尚未建立訪視的應收預估、較大量非同步匯出及完整監測操作。
- ICF 集中保管、附件存取及更完整的撤回／保存政策；本機 MVP 已有 ICF 內容設計與獨立核准，採院端文件參考。
- 正式帳號佈建、OIDC／MFA／CSRF／登出／撤銷驗收，平台登入與外部單一登入。
- 實際 CTMS 跨站嵌入與 IdP 服務帳號聯調、完整讀取契約、事件派送及對帳；目前已有外部訪視與本機嵌入，並以實際簽章 token 驗證 Bearer middleware。
- 一般附件與既有 CBCT 服務銜接、檔案驗證與保存控制。
- 即時 AI 文件轉表單依 ADR 0019 延後；目前保留 YAML／JSON 草稿匯入及人工編輯。
- 全階段操作／安全／容量測試、復原演練、正式部署與院所試點驗收。
