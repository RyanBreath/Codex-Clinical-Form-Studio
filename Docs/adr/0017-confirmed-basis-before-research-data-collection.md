# 確認適用依據後才開放研究資料收集

使用者選擇在授權研究人員確認適用的同意或免同意依據之前，阻擋 eCRF 輸入與研究附件上傳；確認前可建立研究代碼並登錄或補齊同意依據。相較於允許受限草稿或僅提醒，此選擇將收集關卡放在實際研究資料進入平台之前，不以尚未送出為理由允許預先收集。

此規則適用本平台介面、嵌入介面、附件上傳授權與外部寫入 API，且須在後端執行；ICF 依據文件的登錄與適用的受限上傳須與研究附件收集區分，避免阻擋確認依據本身。系統可接受已確認的適用免同意依據，不強制每筆資料都必須有已簽 ICF。

預設阻擋，例外僅可依研究核准流程明確設定，不提供填寫者自行略過。確認人權限、用途及版本適用範圍、失效或撤回後的控制、例外的審核與版本，以及對已存在資料的處置仍待設計。本決策為平台控制政策，不代表系統自行判定法律上有效同意或免同意。
