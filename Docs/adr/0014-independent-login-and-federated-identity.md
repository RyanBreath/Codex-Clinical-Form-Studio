# 支援平台登入與外部單一登入，研究授權由本平台控管

使用者選擇同時支援平台獨立登入與機構／CTMS 單一登入，先交付平台登入，再加入外部登入整合。可評估重用既有 CBCT 平台的身分驗證基礎，但本平台獨立管理研究角色與院所存取範圍，讓沒有外部身分系統的研究仍可使用，也保留整合時減少重複登入的能力。

外部登入成功只確認身分，不能直接取得研究權限；同一人跨來源登入的帳號連結、嵌入時的授權交換、帳號撤銷與工作階段失效仍須設計。不以相同 Email 自動推定為同一帳號，也不直接信任 CTMS 傳入的研究或院所角色。本決策未指定身分供應商或自行實作密碼驗證。
