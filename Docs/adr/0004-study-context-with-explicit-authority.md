# 支援獨立建檔與 CTMS 脈絡整合，明確指定維護來源

使用者選擇同時支援本平台建立研究案、院所及受試者研究代碼，以及接收 CTMS 提供的研究脈絡；每個研究須明確指定維護來源。開發順序先提供本平台建檔，再加入 CTMS 外部代碼對應，以兼顧獨立使用及既有系統整合，避免兩端各自維護同一份脈絡而發生衝突。

外部代碼須保存來源與適用範圍，不以字串相同自動合併受試者。無論脈絡由何處維護，填答正式紀錄仍依 ADR 0001 保存在本平台；本決策不授權同步姓名等直接識別資訊。維護來源切換、既有資料對應與衝突處理流程仍待設計。
