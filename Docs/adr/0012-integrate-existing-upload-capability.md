# 整合既有上傳能力，先文件附件再 CBCT

使用者選擇表單平台整合既有 CBCT 上傳能力，交付順序先一般文件附件，再串接 CBCT／DICOM。表單平台管理附件用途、研究／受試者／訪視及表單關聯與使用權限，上傳服務負責傳輸、續傳、完整性與適用安全及格式驗證，以重用既有能力並保留兩個系統各自使用的可能。

此處確認的是能力與責任分工，不預設必須把既有程式拆成微服務或搬移資料。後續需定義上傳授權、穩定檔案識別、驗證結果同步與重試、受控下載及刪除／保存協調；不同系統的 ID 不得直接假設一致。表單可關聯附件不代表已取得檔案存取權；已簽 ICF 另受 ADR 0011 的保管與權限政策限制，檔案驗證通過亦不取代同意與研究使用檢查。
